# react-worker-uploader

A lightweight, customizable React hook for uploading and parsing large CSV/JSON files using Web Workers — without blocking the main thread. 🧠⚡

## ✨ Features

- ✅ Parse large files without freezing UI
- 🔧 Custom file validation/transformation via external function
- 📂 Supports CSV and JSON
- 🧩 TypeScript ready
- 🛠️ Dev-friendly API with `onError`, `onParsed`, `onFinish`, etc.

## 📦 Installation

```bash
npm install react-worker-uploader
# or
yarn add react-worker-uploader
